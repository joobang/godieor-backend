DATA73 현재 KR/WORLD 게임+EPL의2026~2027 월별24창/API30115개 ID는 DB와 일치했다. 이는 전체 레코드를 외부 원천으로 다시 검토한 것과 다르며, 게임 외부 비교는35표본/EPL 신규380 전체다. 실제 API/DB 확인과 자동 운영·전수 정확성을 구분한다.

OTT09시 launchd의 실제 기동 관측은 DATA71, 새 단계 별도 실행은 DATA72다. DATA73의 영화/게임/EPL은 수동 백필·강제 일일 실행으로 확인했으며 별도 로컬 일간 등록·다음 자동기동을 완료했다고 하지 않는다. 서비스 Cron은 활성 프로세스/설정이 필요하고 GitHub Actions도 원격 push/운영 검증 전이다.

제품 조회2026년 이후와 수집의 미래400일/다음 해/다음 시즌·현재 두 달은 다르다. 이 범위를 모든 발표된 미래 일정이라고 표시하지 않는다. 알려지지 않은 날짜를 만들거나 목록 부재만으로 취소하지 않는다. 뮤티니처럼 동일 공식 ID의 명시 날짜 철회는 미정/이전 날짜 이력으로 반영한다.

다음은 IGDB49 원천 ID 검토·미정/ID 이동 추적, 영화/게임/EPL의 실제 일간 실행 설정·복구, OTT 신규 시즌/나머지 원천 일반 자동 검토다. 이 데이터 단계 종료 후 배포→기본기능→디자인 순서를 유지한다.
