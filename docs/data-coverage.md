범위를 제한한 소스가 모든 발표된 미래 일정을 수집한 것으로 표시되지 않도록 한다. 위 DB 날짜는 원천의 지원 기간을 보장하는 값이 아니다. date_only는 SQL date 문자열로 관측했고 UTC 자정을 만들지 않았다.

OTT 일간09시 launchd는 등록·오늘09시 실제 기동 관측이 있으며 이번 새 단계는 별도 실제 실행으로 확인했다. 새 단계가 다음09시 자동 실행에서 성공한 것으로 미리 세지 않는다. 영화/게임/EPL의 서비스 Cron은 별도 설정·실행 프로세스가 필요하며 현재 일일 운영을 이 OTT 작업만으로 보장하지 않는다.

다음 데이터 작업은 공식 원천 신규 시즌/나머지 OTT 자동 검토 범위 확대와 영화·게임·EPL의2026년 백필/최신 갱신을 실제 실행하는 것이다. 새 정상 입력, DB/API 보존, 일일 실행/복구를 충족하기 전 배포 단계로 넘어가지 않는다.
