DATA74 현재 KR/WORLD 게임+EPL의2026~2027 월별24창/API30125개 ID는 DB와 일치했다. 기존32683 event행·ID·이력 보존/실제 신규게임10 모두 공식 작품ID·본편/플랫폼/지역·날짜 및 상세API200을 확인했다. 이는 전체 레코드를 외부 원천으로 다시 검토한 것과 다르다. DATA73 게임35표본/EPL 신규380 전체 대조도 기존 근거로 유지한다. 실제 API/DB 확인과 자동 운영·전수 정확성을 구분한다.

OTT09시 launchd의 실제 기동 관측은 DATA71,새 단계 별도 실행은 DATA72다. DATA74에서 영화/게임/EPL의08:30 KST LaunchAgent를 실제 등록하고 명시OS기동3회/당일9skip·제어된 KOBIS연결실패 격리/마지막성공 보존·정상9범위 수집 복구를 확인했다. 다음 자연08:30 기동은 아직 관측하지 않았다. 로그인된 Mac/가용DB가 필요하며 원격 상시운영이나 GitHub Actions push·클라우드 배포 검증과 구분한다. 운영 절차는 docs/provider-daily-operations.md.

제품 조회2026년 이후와 수집의 미래400일/다음 해/다음 시즌·현재 두 달은 다르다. 이 범위를 모든 발표된 미래 일정이라고 표시하지 않는다. 알려지지 않은 날짜를 만들거나 목록 부재만으로 취소하지 않는다. 뮤티니처럼 동일 공식 ID의 명시 날짜 철회는 미정/이전 날짜 이력으로 반영한다.

다음은 IGDB 원천지역 provenance·미검증/중복 이벤트 게시 상태와 공용ID·찜 참조의 분리/alias 처리,미정 게임 수집,OTT 신규 시즌/나머지 원천 일반 자동 검토다. 현재49건의 날짜·비본편·가능 중복이 교정됐다고 하지 않는다. 데이터 단계 종료 후 배포→기본기능→디자인 순서를 유지한다.
