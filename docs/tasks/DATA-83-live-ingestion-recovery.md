## 실제 원인과 수정

- 수정 전 KOBIS 공식 목록 조회 성공 247개, 기존 게시 1,909개 대비 누락 1,662개. 이 중 1,661개는 2026-10-01 이전 날짜, 1개는 날짜 미정이었다. 이전 영화들을 그대로 재조회하려다 `PROVIDER_RECHECK_LIMIT`에 걸려 수집 전체가 `COLLECTION_FAILED`로 종료됐다.
- `KobisAdapter.refreshMissing`에서 과거 `date_only` 이벤트만 상세 재확인 대상에서 제외한다. 현재 기간과 날짜 미정 작품은 기존과 같이 재확인해 공식 날짜 철회를 반영한다. 과거 영화의 기존 이벤트·source·history DB 행은 삭제하지 않는다.
- Node 24 빌드 성공, KOBIS 관련 9/9 테스트 통과, 전체 343/343 테스트 통과. 로컬 공식 KOBIS 재실행 성공: `node --env-file=.env dist/src/cli/collect-daily.js --mode daily --providers kobis --force` → `published=248`.
- 읽기 전용 DB 재집계(15:27 KST): 영화 1,911, 게임 29,927, EPL 761, OTT 96. 총 32,695행. 기준 이전 25,808행은 ID·이력과 함께 보존. 실제 데이터가 로컬 DB에 있다고 원격 환경에 있다고 주장하지 않는다.

- Provider 강제 실행: EPL 1범위/IGDB 7범위 성공, KOBIS는 위 수정 후 별도 재실행 성공. 이어 15:32 KST 통합 daily 재실행에서 9범위 모두 당일 성공 이력에 의해 skip, `completed`/exit0 확인. 이 skip 실행은 신규 수집으로 중복 집계하지 않는다.
