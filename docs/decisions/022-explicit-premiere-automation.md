# ADR-022 · 신규 공식 첫 공개 근거와 작품 식별의 자동 검토

2026-11-16 구현 선택. 제품의 정확한 KR 플랫폼 첫 공개 정책을 재사용한다. 독립 승인이나 전체 수집 완료 선언이 아니다. DATA-69 / LEARN-0021.

기존 `auto-review-verified-premieres`는 curated binding이 있던 작품만 재검토한다. 신규 작품은 binding이 없으므로 기존 검증을 반복해도 새 게시가 생기지 않는다. 쿠팡 공식 추천작 기사는 작품별 공개란과 출연진을 제공하지만 기존 수집기는 제목만 보존했다.

`collect-coupang-premieres`는 canonical URL·공식 추천작 제목·원문 날짜 문맥을 검사하고 `cpnr-intro`의 작품별 필드를 분리한다. 연도 없는 월일은 기사와 같은 연월일 때만 기사 연도를 문맥으로 사용하며 요일 충돌/날짜 오류/다른 달/연도만 표시는 보류한다. 기사 게시일을 작품 공개일로 쓰지 않는다. ‘부터 매주’는 제공 시작 주장으로 보존하고 일반 회차나 최초 공개를 자동 확정하지 않는다.

자동 검토는 해당 작품의 공개란에 `첫 공개` 또는 `최초 공개`가 있고, 자산 공개·재공개·해외·극장 문맥이 아니며 정확한 날짜가 있을 때만 가능하다. 검색은 영화/TV 모두 최대 5페이지의 끝까지 확인하고 제목 일치·서로 다른 출연진 2인 이상을 대조한다. 검색 잘림/정체성 조회 실패/복수 일치는 보류한다. TV는 원문 시즌 번호와 TMDB 시즌 상세·첫 회 일치가 필요하다. 한국 플랫폼 날짜는 원문을 보존하며 글로벌 첫 방영일로 바꾸지 않는다.

이 조건을 만족하면 historical curated binding 없이 현재 원문 revision에 검토를 저장하고 기존 opaque key 생성·게시 경로로 넘긴다. 기존 reviewed 후보는 보존하고, 기존 curated binding 또는 자동 검토의 TMDB 정체성이 같은 작품·시즌·플랫폼을 다시 승인하지 않는다. 현재 실제 3개 공개일 주장은 명시 첫날 또는 식별 근거 부족으로 모두 보류됐다. 이 파서가 모든 공지 표현을 이해하거나 첫 공개를 전수 확정하는 것은 아니다.

일간 실행기는 Node 24를 요구한다. launchd는 현재 KST 시스템에서 오전 9시에 영속 경로의 Node 24.22.3을 사용하도록 재등록했다. 마지막 실행에 단계 결과를 저장하며 제한시간 초과 시 같은 process group의 수집 후손까지 종료한다. 이 종료 제어는 OS 권한 격리와 다르다. 강제 종료 후 소스별 stale writer lock은 실제 소유 프로세스를 조사해야 하며 무조건 자동 삭제하지 않는다.

자체 근거는 DATA-69 evidence와 276개 검사, 실제 하위 프로세스 종료 검사, 가상 근거→일회용 PostgreSQL 신규 저장·재조회·반복 게시 검사다. 실제 신규 자동 게시0 및 독립 리뷰 미실행은 남는다. 새로운 공지 형식과 정책·식별·시즌 처리 변경 시 이 결정을 재검토한다.


## DATA-70 · 자동 승인을 확장하지 않고 실제 공식 근거를 작성자 검토

2026-11-16: DATA-69의 실제 신규0은 당시 결과다. DATA-70에서는 Netflix 공식 KR 일정과 같은 작품 상세의 식별·형태·최초 작품 날짜, Disney+ 한국 상세의 명시 공개 배너, TVING 작품 P ID와 공개예정/openText, Coupang 작품별 신규 제공 문맥과 시즌/감독·출연진을 작성자가 검토해23개를 실제 게시했다. 로컬70→93, 기존70 event 전체행/ID/이력 보존, 재게시 신규0, API 새23개 확인. curated 입력은 ott-source-reviewed-batch-2026-11-16.json이다.

이것은 좁은 자동 파서에 없는 표현을 수동 근거 검토 경로로 처리한 것이다. '첫 공개'라는 문자열만 없는 공식 발표를 무조건 영구 보류하지 않으며, 공식 날짜·작품 ID·국가·형태·첫 제공 문맥을 종합 검토한다. 단순 availability/글로벌 방영일만으로 게시하는 예외는 만들지 않았다. 원천 자체 ID로 확실히 구분되는 작품은 TMDB 번호가 없어도 독립 source identity로 보존한다. 미확정 TMDB ID/시즌을 생성하거나 제목으로 다른 출처와 병합하지 않는다. 데이터 검토와 verifier의 독립 기준/승인 상태는 별개다. 현재 자동 검토 조건 및 독립 승인 경계는 그대로다.


## DATA-71 · 게시 후 원천 재검증의 결속과 변경 감지

2026-11-17. DATA70으로 추가한23건이 고정 reviewed 입력에만 남으면 일간 재게시 성공을 원천 재확인 성공으로 오해할 수 있다. 그래서 일간 경로에 읽기 전용 재검증을 추가했다. 검토 batch 지문·현재 review 전체 값/ revision·고정 매핑을 결속하고, 공식 날짜/시즌/작품·형태와 작품별 식별 근거를 비교한다. 실패/변경은 보고서와 exit2에 남기고 기존 데이터를 자동 덮어쓰지 않는다. 이는 신규 최초일 승인이나 독립 verdict가 아니다.

실제 Netflix의 한국로케일 canonical 이동은 같은 host의 locale=ko-KR 경유와 최종 작품ID를 확인하며 처리한다. 같은 실행의 Netflix 수집본은 시간·국가·원천·월 범위를 검증한 경우에만 재사용한다. 과거월 catalog-only 확인과 현재 KR 일정까지 대조한 확인을 구분한다. Coupang의 표에 없는 기수는 원 검토의 지문에 결속한 그 작품 자체 heading 문구가 현재도 남는지 확인한다. 기사 전체의 다른 작품이나 현재 시즌 개수로 번호를 추정하지 않는다.

2026-11-17 첫09시 launchd 실제 실행의93 게시/부분 완료를 관측했고, 새 단계는 연결 후 별도 실제 실행으로23/23 확인했다. 최종 자체검사288·기존93event/ID/이력·API 보존은 작성자 검사이며 전체 커버리지/실폰/독립 승인과 구분한다. 원본 DATA-71/evidence 및 LEARN-0021.

## DATA-72 · Netflix 최초 작품 공개의 일반 자동 검토

KR 공식 신규 일정의 videoID와 해당 한국 작품 페이지를 결속한다. 작품 제목·최종 canonical ID·Movie/TVSeries·dateCreated의 유효한 달력 날짜가 일치하면 기존 curated TMDB binding 없이 신규 검토를 생성한다. dateCreated 단독으로 KR 제공일을 결정하지 않는다. 기존 첫날과 다른 목록 날짜는 시즌 근거가 아니며 시즌 개수를 추정하지 않는다. 공식 genre에 따른 다큐/애니 형태와 알려지지 않은 season=null을 유지한다. 같은 canonical 별칭과 기존 검토 충돌은 신규 승인을 막는다.

이 경로는 새 시즌 일반 판정이나 모든 제공처 검토 자동화가 아니다. 리뷰/현재 source revision 결속·최신 일정·제한 redirect/재시도·실패 전파를 검사한다. 기존 리뷰는 보존하며 원천 실패는 별도로 보고한다. DATA72 실제 공식 입력을 보존된 미검토 상태에 재생한 일회용 DB에서70→84→84와14상세200을 관측했다. 현재 제품은 기존93/오늘신규0이며 이14를 새로운 제품 게시로 다시 세지 않는다. 자체302통과, 전체 데이터·독립 승인/클라우드는 미완료다. 원천 의미/리뷰/정체성·일정 처리 변경 시 이 결정을 재검토한다.
