# ADR-021 · OTT 애니의 분류와 형태

2026-11-16 사용자애니포함확정에따른구현결정. PROD004/005/006/007/009/010, DATA56, LEARN0011/0021. 독립계약/제품승인은대기다.

애니는영화또는시리즈일수있어contentKind=animation과animationFormat=movie|series를함께명시한다. 영화형은시즌을금지하고시리즈시즌은확인된번호또는null이다. 기존documentaryFormat과동시에사용하지않는다. 내부content.kind의기존movie|drama표현은유지하지만공개ottCategory는animation으로보존한다. iOS는‘OTT · 애니’로표시한다. 형식추정으로기존시즌/ID를바꾸지않는다.

API초안draft.5/소비자지문,새migration202611160001을같이작성했다. 과거migration은수정하지않았으며비OTT애니/game형태·영화형시즌을거부한다. 실제로컬migration적용,일회용참조DDL/전체migration경계18/18,현재/고정서버218/218,고정unsignediOS/가상해석을확인했다. 새로운통합runner/독립리뷰/폰UI/클라우드확인은아니다.

초기fresh공식연결3개보정뒤기존70개전수대조로추가1개를발견해최종4개분류를보정했다. 날짜/시즌/플랫폼/ID는유지했다. 총70이벤트/기간68행/다른66전체행·이력불변/반복게시멱등을SQL/API로확인했다. 참조52행의애니는전체6/미일치5,정확26/52는변화없다. 애니범위hold해제는공식날짜게이트해제가아니며새작품자동게시권한은false다.

기존미일치행을범위밖으로치워분모를낮추지않는다. 원천형태·분류·계약·사용자범위가바뀌면이결정과연결학습기록을재검토한다. 날짜근거와분류지원은별개이며리뷰/실행/독립승인상태를혼합하지않는다.
