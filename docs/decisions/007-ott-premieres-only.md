# ADR-007 · OTT 드라마 최초 공개일만 제공

- 날짜: 2026-11-09 KST. 상태: 사용자 범위 확정, 시즌별 최초 공개 포함도 사용자 확정.
- 연결: P05, PROD-005/009. ADR-006의 이벤트/찜 식별자 분리는 유지한다.

사용자가 회차별 날짜 대신 최초 공개일만 원했다. 달력에 드라마 한 작품의 반복 회차가 쌓이는 것을 줄이는 방향이다.
OTT 회차별 공개·완결 이벤트는 V1 수집/API/표시/찜 대상에서 제외한다.
지역·대상 플랫폼에서의 최초 공개를 확인하며 원방영국 최초 방영일과 구분한다.
공개 날짜가 달라지는 지역/플랫폼의 이벤트는 보존한다. 후속 추천안 수락으로 새 시즌도 시즌별 첫 공개일 하나씩 포함한다.
기존 문서의 회차별 찜/신규 회차 자동 포함 제안은 이 결정으로 대체한다.

구현 전 API 계약과 제공처 매핑에서 회차가 최초 공개로 잘못 유입되지 않는지 확인한다.
전 세계 첫 방영일을 한국 OTT 공개일로 대입하는 경우와 동일 작품의 플랫폼별 날짜 차이를 독립 검사 제안에 포함한다.
이번 문서는 범위 결정이며 제공처 연결/실행 검증은 수행하지 않았다.
