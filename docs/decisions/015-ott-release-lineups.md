# ADR-015 · OTT 공개 목록 중심 수집 (2026-11-11)

상태: 사용자 진행 승인 / 구현 단계적 적용. DATA-10. 기존 ADR-010의 뉴스룸 후보 검토·안전장치는 유지한다.

## 결정

- 뉴스룸 RSS는 기사 발견 보조 수단으로 격하한다. 기사 숫자를 작품 숫자나 공개 일정 커버리지로 쓰지 않는다.
- 1차 후보는 서비스별 신작/월간 라인업/공개 캘린더에서 **작품별 행**으로 수집한다. 우선 탐색: TVING Ads 콘텐츠 목록, Netflix Tudum 월별 신규 공개 목록, Disney+ 지역별 공식 라인업, Coupang Play 월별 공개 목록. 이 URL들이 모두 자동 파싱 가능한 것은 아직 확인되지 않았다.
- 자료의 **신규 제공(라이브러리 편입)** 과 **한국에서 해당 서비스 최초 공개**는 다르다. 본문에 국가·최초 공개 근거가 없으면 `market=null`, `premiereConfirmed=false`로 후보만 적재한다. Netflix Tudum 영문/미국 대상 페이지의 날짜를 KR로 복사하지 않는다.
- `sourceUrl`, 확인 시점, 콘텐츠 유형, 시즌 번호, 날짜 정밀도, 원본 근거, 선택적 이미지 주소를 작품별 후보에 보관한다. 정확한 날짜가 없어도 후보로 유지하되 달력에 넣지 않는다.
- 동일 제목도 시즌·서비스·지역·상영 방식이 다르면 별도 이벤트다. 작품 이미지/설명은 TMDB 등의 별도 메타데이터 매칭 후 출처·이용 조건에 맞춰 보강한다. watch provider 가용일이나 TMDB 시즌 air date를 OTT 한국 최초 공개로 추정하지 않는다.
- 기존 제품 DB 게시 절차는 검토된 근거만 허용한다. 목표 갱신 주기는 하루 한 번이며 사이트별 접근 허용·구조·호출 제한을 검증한 어댑터부터 예약 실행한다.

## 이번 구현 범위와 한계

`node scripts/prepare-ott-lineup.mjs input.json output.json`은 사람이/추후 소스 어댑터가 확인한 여러 작품의 공개 목록 JSON을 **검토 대기 후보**로 변환한다. 출처 host, 중복 행, 날짜·시장·최초 공개 근거의 최소 일관성을 검사한다. 자동 웹 탐색·실제 OTT 페이지 파싱·DB 자동 게시/일일 배치 실행은 아직 아니다. 이미지 URL 필드는 후보에만 보관하며 앱 표시를 뜻하지 않는다.

## 출처 검증 과제

- TVING Ads `https://www.tvingads.com/content`: 목록 구조와 정식 공개일/분류/이미지, 페이지 매김, robots/사용 조건을 실응답으로 확인.
- Netflix Tudum `https://www.netflix.com/tudum/articles/new-on-netflix`: 월별 작품 날짜가 다수 포함되지만 KR 공개를 보증하지 않음. 지역 구분 가능한 별도 공식 자료 탐색.
- Disney+/Coupang Play: 국가별 월간 라인업의 안정 URL, 첫 공개일 여부와 게시 가능한 필드 확인.
- 각 소스별 발견 수·정확일자 수·KR 근거 확인 수·검토 승인 수·게시 수를 분리 집계한다. 최소 2회 재수집에 대한 변경 감지·중복 검사 후 자동 주기 연결.

소스 참고: Netflix Tudum 월간 목록, TVING Ads 콘텐츠 페이지, 기존 backend `docs/data-source-assessment.md`. 사이트 공개 열람은 자동 복제 허용의 근거가 아니다.

## DATA-12 보완

Netflix Tudum의 2026년 11월 공식 목록에는 `November 1` → 여러 작품 제목 → `November 5` 등의 구획이 실제 존재함을 공개 검색 페이지에서 확인했다. 이를 저장한 텍스트/Markdown에서 읽는 수동 입력 파서를 추가했다. 영문 원본의 공개 지역은 확정할 수 없으며 원문 HTML 구조·robots·이용 조건 및 한국 라인업은 아직 확인하지 못했다. 수집된 작품을 실제 한국 최초 공개라고 기록하지 않는다.
