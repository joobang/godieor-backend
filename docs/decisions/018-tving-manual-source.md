# ADR-018 · 공식 TVING 작품 링크를 수동 검토 출처로 연결

- 2026-11-13, DATA-51. 구현 결정, 제품/계약 독립 승인 아님. PROD-004/005/007/009, LEARN-0011.

공식 TVING 작품 화면에서 공개 날짜를 확인해도 기존 source enum은 CJ 기사만 받아 실제 날짜가 있는 TVING 원문을 게시 출처로 보존할 수 없었다. CJ 기사 날짜나 방송일로 대체하지 않고 source=tving 수동 경로를 추가한다.

허용은 HTTPS의 정확한 www.tving.com/contents/P숫자 permalink다. login/player/live/다른호스트/임의query는 거부한다. RSS/자동수집 대상에는 추가하지 않으며 소유자 feed가 없다고 자동수집 실패로 기록하지 않는다. 기존 source·후보ID·revision·검토·매핑과 호환된다. API 이벤트 source URL 형식 및 DB/API 계약은 변경하지 않는다.

문무의 공식 화면은 11월14일공개와 방송시각/실제시청시점차이 안내를 함께 표시했다. 날짜만 저장하고 시각을 만들지 않는다. ‘시즌1개’는 개수이므로 시즌번호로 쓰지 않고 null을 유지한다. 다른4개는 가용성/제목/시즌분류만 확인돼 정확한첫날 보류다. 합성 URL경계·날짜/시즌보존 회귀와 실제 SQL/API/재게시 결과는 DATA-51 카드에 기록한다.
