# ADR-005 · 콘텐츠 범위·조회 기간·하루 1회 갱신

- 날짜: 2026-11-09 KST
- 상태: 사용자 정책의 확정 부분 기록. 세부 데이터 확보·실행 설정·검사 기준은 후속.
- 정책 연결: P04~P08. 이 문서는 acceptance 승인이 아니다.

## 최초 답변과 후속 확정

확정: 넷플릭스·디즈니플러스·쿠팡플레이·티빙의 OTT 드라마, 게임 정식 출시,
2026-01-01부터 발표된 미래 일정까지 상한 없는 조회, 정상 수집 하루 1회.
최초 답변에서 모호했던 지역·기기·계정 저장·실패 표시는 아래 후속 답변으로 확정했다.

## 설계 영향

시작 날짜는 2026-01-01 포함이며 실제 날짜 경계의 시간대는 P04 계약에 따른다.
조회 가능한 미래 범위와 한 응답의 크기를 분리한다. 월/기간·페이지 단위로 조회한다.
초기 2026년 이후 이력을 채우는 작업과 정상 일 1회 갱신을 분리한다.
미래는 알려진 일정만 포함하고 미발표나 월/분기 정밀도를 가짜 날짜로 바꾸지 않는다.

API 응답 시각, 원천 수정 시각, 마지막 성공 수집 시각을 분리한다.
EPL 변경이 하루 안에 즉시 반영되는 기능으로 설명하지 않는다.
실행 시각·실패 재시도·데이터 보관 정책은 설계 시 정한다.

## 남은 근거와 검증

4개 OTT의 한국 공개일/회차·2026년 전체 이력을 이미 확보했다고 주장하지 않는다.
각 후보 API에서 접근·지역·정밀도·이력·예정 데이터 범위를 확인하고 출처/미지원 상태를 남긴다.
독립 검사에서 2026년 경계·먼 미래·페이지 누락/중복·미정·갱신 실패를 다룬다.

## 후속 확인 답변

한국/KST 기본 + 국가·시간대 선택, PC·PlayStation·Xbox·Nintendo Switch 정식 출시를 확정했다.
개인 설정·찜은 계정에 귀속하고 서버에 저장해 재로그인·재설치 시 복원한다.
Google 로그인한 사용자는 이용할 수 있고, 빈 필터/미정/연기·취소/갱신 실패는 제안한 표시 방식을 채택했다.
찜 대상 단위는 추가 확인 중이며, 앞 절의 “확인 중”은 최초 답변 당시 상태다.
