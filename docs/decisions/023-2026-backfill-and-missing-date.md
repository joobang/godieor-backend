# ADR-023 · 2026 시작점 고정 백필과 목록에서 빠진 영화의 날짜 재확인

- 구현 결정, DATA73/PROD005~009. 독립 기준의 승인이나 모든 원천 완전성 선언이 아니다.
- 기존 daily는 게임 최근30일·EPL 현재 시즌부터 조회해 과거 누락을 채우지 못했다. backfill도 최근365일/직전 시즌으로 움직여 시간이 지나면 제품 시작2026년을 놓칠 수 있었다.
- 게임 backfill은2026-01-01 UTC 달력일부터, KOBIS는2026년부터, EPL은2026년1~5월이 들어 있는2025 시작 시즌부터 현재/다음 구간을 조회한다. daily의 게임 창은 UTC 날짜 경계·제품 시작점으로 제한한다. 게임 미래400일/KOBIS 다음 해/EPL 다음 시즌이라는 발견 상한은 유지하며 알려진 한계로 공개한다.
- 제공처·mode·force를 명시하는 CLI를 두고 없는 키·잘못된 옵션·수집 잠금 충돌을 성공한 no-op으로 처리하지 않는다. fixture는 이 실제 수집 CLI의 선택 대상이 아니다. 실제 IO는 adapter/repository, 서비스는 조립·검증을 담당한다.

실제 최신 수집에서 영화 뮤티니20268058이 개봉일 검색에서 빠졌지만 DB에는11/18이 남아 있었다. 공식 동일-ID 상세의 openDt가 빈 값임을 확인했다. 일반 목록에서의 부재만으로 취소/미정을 추정하지 않고, KOBIS에 optional refreshMissing hook을 추가했다. repository는 제공처/분야/지역으로 최신 canonical 기록을 읽으며 source ID·variant 일치를 검증한다. adapter는 현재 목록에 없는 기존 작품을 공식 상세로 재확인하고 정확한 날짜 또는 명시 빈 값에 따른 unknown을 돌려준다. 잘못된 ID/잘못된 비어있지 않은 날짜·100건 초과·조회 오류는 전체 scope 게시 전에 실패시켜 기존 데이터를 보존한다. 빈 값에 제작연도를 공개연도로 넣거나 postponed를 추정하지 않는다.

기존 event/content ID와 변경 이력을 유지해 date_only→unknown으로 갱신하고 이전 날짜는 history/API previousTime에 남긴다. 다음날 명시 날짜가 돌아오면 같은 ID로 되돌릴 수 있다. 실제 DB에서 미정 목록 이동·기존 달력 제거·반복 재수집 이력 불변을 확인했다.

IGDB의 기존49 release ID는 이번 full backfill에 없고 동일 ID 재조회도200/빈 배열이었다. 삭제/이전 원인은 확정하지 못했다. 이 사실은 명시 날짜 철회와 달라 임의 삭제·취소·재매핑하지 않는다. old observedAt과 데이터/찜 참조를 보존하고 공개된 검토 대기로 남긴다. 새 ID의 동일 작품 여부 및 날짜 미정/변경 추적은 후속이다.

자체310개, 고정digest 일회용DB 회귀, 실제 SQL/API/공식 게임35표본·신규EPL380경기 대조가 근거다. 게임25044/EPL380/영화7의 실제 새 이벤트가 게시됐으며 source scope는 partial이다. 데이터 전수·일일 원격 운영·독립 승인/실폰·클라우드를 대신하지 않는다. 원천 의미/제품 시작점/범위/재확인 정책이 바뀌면 이 결정을 재검토한다.
