# ADR-017 · OTT 다큐의 분류와 형태

- 2026-11-13, DATA-48, 사용자 제품 범위 확정에 따른 구현 결정. 계약/acceptance 독립 승인은 대기.
- 관련 PROD-004/005/007/009/010, LEARN-0011/0015. 한국 플랫폼·날짜 근거와 고정 ID 원칙 유지.

다큐는 영화 또는 시리즈일 수 있어 장르와 형태를 같은 값으로 취급하면 시즌과 콘텐츠 키가 잘못 저장된다. 검토 입력에서 contentKind=documentary와 documentaryFormat=movie|series를 함께 요구한다. 영화형은 시즌을 금지하고 시리즈는 확인된 시즌만 저장하며 없으면 null이다. 기존 검토 입력은 호환된다.

공개 API는 ottCategory=documentary를 보존하고 iOS는 ‘OTT · 다큐’로 표시한다. 내부 content_kind는 기존 movie/시리즈용drama를 유지한다. 다큐를 영화/드라마 분류로 바꿔 게시한다는 뜻이 아니다. 새 migration202611130001이 다큐 영화·시리즈를 허용하고 비OTT 다큐 분류와 영화형 시즌은 거부한다. 과거 migration은 불변이다.

초안 계약0.1.0-draft.4/manifest와 소비자 참조를 함께 고정한다. 실제 후보 게시·실기기 표시·독립 승인과 지원 코드 구현을 구분하며 검사 결과는 DATA-48에 남긴다. 캐런 리드 후보는 현재 작업에서 자동 게시하지 않는다.
