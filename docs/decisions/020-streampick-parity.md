# ADR-020 · OTT 참조 목록의 항목별 일치 게이트

2026-11-13 구현 결정/진행. 원본 DATA-53, LEARN-0021. 사용자 우선순위는 StreamPick 신작·시즌 첫 공개 대조이며 회차 확장은 제외한다. 실사용자 장애·독립 승인이 아닌 작성자 원문/코드/로컬DB 관측이다.

기존 Python 비교는 eventType=new_release만 포함해 episode 타입이면서 premiere=true인 새 시즌을 제외했다. 같은 최신 HTML에서 기존 분모21→수정47 플랫폼행이며 26행이 누락됐다. 월별 페이지는46행으로 전체 달력의 스폰지밥 시즌18 한 행과 다르다. 이 차이를 삭제하지 않고 보존한다.

작품 총수보다 참조의 작품/시즌/플랫폼/날짜별 일치를 판정한다. 실제 제품DB63행은 참조47행보다 많지만 최초 정확 일치는14행뿐이었다. 검토한 별칭은 날짜/서비스/시즌에 결속하고, 시즌 미상은 정확 일치로 계산하지 않는다. 빈/중복 참조는 거부하며 --require-parity는 단 하나의 미일치에도 exit2다. 조회/입력 오류는 exit1, 정확 일치만 exit0다. 공개 원문 수집→시즌 포함 참조→DB 대조를 한 로컬 읽기 전용 명령으로 재실행할 수 있다. 정기 예약/배포는 추가하지 않았다.

공식 작품별 첫 공개일을 확보한 TVING3·Disney+1과 기존4개 미상 시즌 보완을 전체 prepareReviewed 사전검사 후 한 묶음 게시했다. 기존 이벤트ID/국가/플랫폼/날짜는 보존한다. StreamPick/TMDB 날짜+현재 제공처가 공식 해당 시즌의 한국 플랫폼 공개일을 증명한다고 간주하지 않는다. 특히 이전 시즌이 Netflix에 있다고 새 Disney+ 시즌의 Netflix 날짜를 생성하지 않는다. 사용자는 미확인 일정 표시 변경 대신 TMDB 기반 발견과 공식 루트 검증을 결합하는 수집 로직을 지시했다. 미확인 일정의 제품 표시를 추가하지 않는다.

검사 결과 Node24 서버159/159·Python9/9, SQL/API/반복 게시 확인. 현재67행·정확24/47, 미일치23으로 실제 게이트 exit2를 유지한다. 관련 추출 형식·별칭·게시/계약이 바뀌면 재검토한다. 앱 실폰·클라우드·독립 runner/승인은 미실행이다.


## 2026-11-16 · TMDB-first 수집 및 공식 검증 연결

StreamPick은 참조 측정에만 사용한다. 수집은 TMDB의 월별 air_date/first_air_date/영화 날짜와 KR 제공처 검색, 제공처가 아직 없는 한국 예정작 검색을 독립적으로 수행한다. 예전 시리즈의 해당 월 새 시즌을 조회하고 시즌 첫날과 첫 회 날짜가 다르면 충돌로 보존한다. 시리즈 watch/providers는 발견 힌트로 유지하고 해당 시즌 endpoint와 구분한다. lookup 실패·미등재는 제공 없음으로 확정하지 않는다.

공식 루트는 OTT 정식 API가 아니다. 기존 검토 자료의 명시 TMDB ID·시즌·국가·플랫폼 연결을 재사용하고 Netflix KR 공개 목록 전체 페이지, TVING 공식 작품의 명시 공개 문구/작품 ID를 다시 확인한다. 방송일 alone/시즌 개수는 공개일/시즌 번호를 증명하지 않는다. 미지원 공식 파서는 성공으로 간주하지 않는다. 공식/TMDB 날짜 충돌과 애니 범위 검토 대상은 후보에 남긴다. 모든 후보는 publishingAllowed=false이며 신선한 공식 근거와 원본 review/revision/고정 키 결속을 통과한 묶음만 기존 게시 입력으로 연결한다.

stable ID와 의미 데이터 hash로 후보 revision을 관리하고, 재조회 시각만 바뀌면 revision을 늘리지 않는다. 동일 실제 관측 재처리에서0신규/0revision 증가 확인. 잠금은 동일 로컬 디렉터리 writer 협약이며 OS 격리 보장 아님.

최신 측정: 독립 발견312작품+공식 ID 보완 후325작품→현재 후보120행/누적 저장123ID, 공식 재확인39행은 기존69개 고정 게시 입력과 결속(신규 키0). 최신 참조52행의 후보 발견49행/제품 일치26행, SQL/API67행. Node24 서버183/183·Python9/9. Coupang 영화 provider 미등재로 수집 complete=false, 제품 일치 게이트도 exit2. 이전11/13의47행/24일치와 구분하며 전체 정확성·독립 승인을 주장하지 않는다.

근거: TMDB 공식 discover/season/watch providers 문서 및 StreamPick 공개 소개. 내부 StreamPick 구현을 확보한 것은 아니며, 시리즈 제공처+시즌 첫날 조합과 공개 데이터의 일치 관측으로 추론한다.
